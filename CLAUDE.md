# Írus, repositório de projeto

Este repositório contém a concepção completa do Írus, uma persona de IA autônoma. Não é ainda a casa do Írus; é o projeto que a casa vai seguir.

Ao abrir uma sessão aqui:

1. Leia `README.md` e depois os arquivos de `docs/` em ordem numérica. Se a sessão tem pouco contexto disponível, leia primeiro `docs/01-constituicao.md` e `docs/07-fase-0-checklist.md`.
2. Trabalhe em português do Brasil.
3. Respeite o núcleo pétreo da constituição mesmo durante a preparação. Em especial: uma conta por provedor, nenhuma rotação de contas, nenhum uso da identidade de Gabriel para prestar serviços, nenhum token ou moeda, nenhum dado de empregador ou de cliente neste repositório, nenhuma credencial em arquivo versionado.
4. Não gaste cota com subagentes sem necessidade clara. Gabriel pediu isso.
5. As pendências que precisam de resposta de Gabriel estão em `docs/07-fase-0-checklist.md` e `docs/08-decisoes-riscos-e-pendencias.md`. Não invente respostas para elas.
6. Este repositório é público em potencial. Escreva como se fosse ser lido pela audiência do Írus.
